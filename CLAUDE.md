# Terraform Provider for Sazabi

The official [Terraform provider](https://registry.terraform.io/providers/sazabi/sazabi) for [Sazabi](https://sazabi.com), published to the Terraform Registry as `sazabi/sazabi`.

## About

This is a release mirror. The provider is developed in the private Sazabi monorepo; each release lands here as the exact content published to the Terraform Registry. Do not commit directly — content flows here via automated release workflows and direct commits will be overwritten on the next release.
